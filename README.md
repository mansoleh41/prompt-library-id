# prompt-library-id

Pustaka prompt Bahasa Indonesia siap salin-tempel untuk kerja, data, dan dokumen.

- `prompts/kerja.md` – email, notulen, balasan pelanggan
- `prompts/data.md` – analisis data & riset
- `prompts/dokumen.md` – penyuntingan & presentasi

Kontribusi: tambahkan prompt dengan format judul + blok kode. Lisensi: MIT
