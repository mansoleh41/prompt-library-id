# Prompt Dokumen & Presentasi

## Rapikan tulisan
```
Perbaiki ejaan (PUEBI/KBBI), tata kalimat, dan alur teks ini tanpa mengubah makna. Tampilkan hasil bersih lalu daftar perubahan utama.
```

## Kerangka presentasi
```
Buat kerangka presentasi [topik] untuk [audiens], durasi [menit]. Per slide: judul pesan, 3 poin, saran visual.
```
